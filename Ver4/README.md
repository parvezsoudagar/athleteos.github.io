# AthleteOS Ver4
Alternative marketing-site concept with shorter, higher-impact copy.

Highlights:
- Keeps AthleteOS logo mark, navy/gold palette, tagline and footer line.
- Interactive flip cards: click/tap a card to reveal detail; click it again or anywhere else to close; opening another closes the previous card.
- Responsive desktop/tablet/mobile layout.
- Stronger visibility for ratings/rankings, achievements/badges, multi-sport league weightage, sport scoring, auctions, role-based operations, and player/team/club analytics.
- Static HTML/CSS/JS; suitable for GitHub Pages.

Files:
index.html, platform.html, competitions.html, community.html, interclub.html, contact.html, styles.css, site.js

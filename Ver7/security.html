Security & Privacy

Designed to connect sport.
Not collapse trust boundaries.

AthleteOS treats club data, cross-club events and public Community tournaments as different trust environments, with permission-aware access and accountable privileged actions.

DEDICATED

Dedicated club data environment

Each club can operate in its own data environment rather than sharing one private membership schema with other clubs.

LEAST PRIVILEGE

Scoped access

Roles are designed around the exact club, event, team, match or administrative action a person needs.

MFA

Privileged protection

Administrative and operator roles are designed for named identities, multi-factor authentication, expiry and revocation.

AUDIT

Accountable changes

Official result corrections and critical privileged changes are designed to leave an audit trail rather than silently overwrite history.

Clear trust zones

Private club sport.
Cross-club sport. Public sport.

The product separates these use cases so public participation does not become an indirect route into private club data.

CLUB

Dedicated club environment

Members · families · bookings · coaching · private club competition history

FEDERATION

Event-scoped cross-club layer

Approved participant identity · teams · fixtures · results · standings

COMMUNITY

Public-facing event layer

Registration · consent · approved photos · public scoring · results

Public by choice

Public pages use
deliberately selected data.

AthleteOS public experiences are designed around dedicated public views rather than exposing the same private member object used by club administrators.

CAN BE PUBLIC

Sporting information

Approved display name · club/team · fixture · result · ranking/stat where permitted · approved event photo

PRIVATE BY DEFAULT

Membership information

Private contact details · family relationships · member number · guardian data · internal notes · incident information

Privileged access

Named people.
No anonymous administrators.

Community organizers, scorers and Federation operators can be time-limited and event-scoped. Support access can be temporary rather than permanently universal.

ADMIN

Named account

One accountable identity per privileged user.

MFA

Second factor

Additional protection for high-impact roles.

SCOPE

Only what is needed

Club, tournament, team or match permissions.

EXPIRY

Temporary access ends

Organizer/scorer grants can automatically stop after the event.

Deployment choice

Managed cloud or
approved private deployment.

The same AthleteOS product is designed to support managed cloud deployment and controlled private/on-prem environments where required.

Security is a release requirement.

AthleteOS is designed to validate security, backups, permissions and deployment readiness before a release is described as production-ready. No software should be described as completely secure; controls must be implemented, tested and continually maintained.
